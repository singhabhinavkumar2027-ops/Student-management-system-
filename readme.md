STUDENT MANAGEMENT SYSTEM 
Project Description:
Student Management System is a command-line application that allows users to manage student records.
This is a simple student management system that allows you to add, view, search, delete, and update student records. The system uses a list to store student information, which includes roll number, name, and age.
Features:
1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Update Student
6. Exit
7. Calculate percentage
8. Calculate grade
9. Simple user interface

Technologies Used:
Python
Lists
Dictionaries
Fucntions
Loops
Conditional statements
User Input

Reqirements:
Python 3.x
NO additional libraries are required to run this project.

How to run the project:
1. Clone the repository or download the source code.
2. Open a terminal and navigate to the project directory.
3. Run the command `python main.py` to start the application.
After running the program,a menu will be 
1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Update Student
6. Exit
Enter the choice you want to enter.
